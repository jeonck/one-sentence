## Today's Sentence

**"Starting from scratch."**

> 아무런 준비 없이 맨 처음부터(원점에서) 시작하는 것.

### 단어 풀이

| 단어 | 발음 | 뜻 |
|------|------|-----|
| start | [스타트] | 시작하다 |
| from scratch | [프롬 스크래치] | 맨 처음부터, 아무것도 없는 상태에서 |

### 활용 예문

- We had to build the whole system from scratch. (우리는 전체 시스템을 맨 처음부터 다시 구축해야 했다.)
- It's hard to start a new career from scratch, but it's worth it. (새로운 커리어를 맨바닥에서 다시 시작하는 건 힘들지만, 그만한 가치가 있어.)
