## Today's Sentence

**"I think it's because love is something that starts as a feeling."**

> 내 생각에 그건 사랑이 '감정'으로 시작하는 대단한 무언가이기 때문인 것 같아.

### 단어 풀이

| 단어 | 발음 | 뜻 |
|------|------|-----|
| because | [비코즈] | 왜냐하면 ~이기 때문에 |
| something | [썸띵] | 무언가, 어떤 것 |
| start as | [스타트 애즈] | ~로 시작하다 |

### 활용 예문

- I think it's because we need more time.
- Great friendships often start as a simple conversation.

하루 한 문장으로 영어 실력을 쌓아봐요! 💪
