## Today's Sentence

**"They told me to handle it myself"**

> 저보고 알아서 하래요

### 단어 풀이

| 단어/패턴 | 발음 | 뜻 |
|-----------|------|-----|
| told me to | | 나에게 ~하라고 말했다 |
| handle it | | 그것을 처리하다 |
| myself | [maɪˈself] | 나 스스로, 직접 |

> 💡 **Tip:** "알아서 하다"는 상황에 따라 여러 표현이 가능하지만, 직접 문제를 처리하라는 의미일 때는 **"handle it myself"** 라고 표현할 수 있습니다.

### 활용 예문

- You should handle it yourself.
  (네가 알아서 처리해.)

- Can you handle it yourself?
  (너 혼자 알아서 할 수 있겠어?)
