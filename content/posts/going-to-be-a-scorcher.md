## Today's Sentence

**"It's going to be a scorcher this summer."**

> 이번 여름은 정말 더울 것 같아 (이번 여름은 타죽을 것 같이 더울 거야).

### 단어 풀이

| 단어 | 발음 | 뜻 |
|------|------|-----|
| scorcher | [스코처] | 불볕더위, 엄청나게 더운 날(여름) |
| it's going to be | [잇츠 고잉 투 비] | ~이 될 것이다, ~일 것 같다 |

> 💡 **Tip:** **"scorcher"** 는 `scorch` (태우다)에서 온 명사로, 불볕더위나 기록적으로 더운 날을 뜻합니다. **"What a scorcher!"** (오늘 완전 불볕더위네!), **"We're in for a scorcher"** (엄청 더운 날이 될 것 같아)처럼 쓸 수 있어요. 비슷하게 **"It's going to be a brutal summer"** (이번 여름은 정말 힘들 것 같아), **"We're in for a hot one"** (더운 여름이 될 것 같아)도 원어민들이 즐겨 씁니다.

### 활용 예문

- "Have you seen the forecast?" / "Yeah, **it's going to be a scorcher this summer.** I'm already dreading it."
  ("일기예보 봤어?" / "응, **이번 여름 진짜 더울 것 같아.** 벌써부터 걱정돼.")

- **It's going to be a scorcher this summer** — they're already predicting record-breaking temperatures.
  (**이번 여름은 정말 불볕더위일 것 같아** — 벌써부터 기록적인 기온을 예측하고 있대.)
