## 오늘의 한 문장

> "Perfection is not attainable, but if we chase perfection we can catch excellence."
>
> — Vince Lombardi, *Address to the Green Bay Packers* (1959)

---

## 왜 이 문장인가

전설적인 미식축구 코치 빈스 롬바르디가 그린베이 패커스 첫 훈련에서 한 이 말은 단순한 스포츠 명언을 넘어 일상과 비즈니스에서 널리 인용되는 실용 영어 표현의 교과서입니다. 조건절(if절)과 주절이 "chase(쫓다)"와 "catch(잡다)"라는 의미상 짝을 이루어 역설적인 메시지를 전달하는 구조가 매우 인상적입니다. 목표 달성·자기계발·팀 리더십을 이야기할 때 이 문장의 패턴을 직접 활용할 수 있습니다.

---

## 핵심 표현 분석

| 표현 | 뜻 | 뉘앙스 |
|---|---|---|
| **attainable** | 달성 가능한 | "achievable"보다 공식적이며, 이상이나 목표가 실제로 손에 닿는지 논할 때 사용 |
| **chase (something)** | ~을 추구하다, 쫓다 | pursue보다 능동적·열정적 — 단순히 바라는 것이 아니라 몸소 달려가는 느낌 |
| **catch (excellence)** | (탁월함을) 손에 넣다 | "chase → catch" 연계 구조로, 쫓는 행위가 결실을 맺는다는 역설적 이미지를 완성함 |

> "PERfection / is NOT atTAINable, / but if we CHASE perfection / we can CATCH excellence."

## 내 문장으로 응용하기

- **원문 패턴:** [Goal] is not attainable, but if we chase [goal], we can catch [achievable result].
- **응용 1:** Fluency is not fully attainable, but if we chase fluency every day, we can catch real progress.
- **응용 2:** Perfection is not attainable in a relationship, but if we chase respect, we can catch genuine connection.
