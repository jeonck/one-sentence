## Today's Sentence

**"Is it true that this app is free to use?"**

> 이 앱 무료로 쓸 수 있다는 게 맞아?

### 단어 풀이

| 단어/패턴 | 발음 | 뜻 |
|-----------|------|-----|
| Is it true that | | ~라는 게 사실인가요? |
| free to use | | 무료로 사용할 수 있는 |

> 💡 **Tip:** 들은 정보가 사실인지 확인할 때 **"Is it true that...?"** 패턴을 유용하게 사용할 수 있습니다.

### 활용 예문

- Is it true that you're moving to Canada?
  (너 캐나다로 이사 간다는 게 정말이니?)

- It's true that the company is facing some difficulties.
  (그 회사가 어려움에 처해 있다는 것은 사실이다.)

하루 한 문장으로 영어 실력을 쌓아봐요! 💪
