## 오늘의 한 문장

> "Taking on a challenge is a lot like riding a horse, isn't it? If you're comfortable while you're doing it, you're probably doing it wrong."
>
> — Ted Lasso, *Ted Lasso* (2020)

---

## 왜 이 문장인가

도전이 편하게 느껴진다면 제대로 하고 있지 않은 것이라는, 성장에 관한 핵심을 유머러스하게 담은 대사입니다. 구동사 *take on*, 부가의문문 *isn't it?*, 그리고 원어민이 부드럽게 단정할 때 쓰는 *probably* 등 일상 회화에서 바로 쓸 수 있는 요소가 가득합니다.

---

## 핵심 표현 분석

| 표현 | 뜻 | 뉘앙스 |
|---|---|---|
| **take on a challenge** | 도전을 떠맡다, 맞서다 | 어려운 일을 자발적으로 맡는 적극적인 느낌 |
| **a lot like ~** | ~와 아주 비슷한 | 비유를 꺼낼 때 쓰는 구어체 표현 (much like보다 캐주얼) |
| **isn't it?** | 그렇지 않나요? | 상대의 동의를 끌어내는 부가의문문, 말투를 부드럽게 함 |
| **you're probably doing it wrong** | 아마 잘못하고 있는 거예요 | 직설을 피하면서도 핵심을 찌르는 조언 패턴 |

---

## 따라 말하기

소리 내어 3번 읽으세요. 리듬과 강세에 집중합니다.

> "TAKing ON a CHALlenge / is a LOT like / RIDing a HORSE, / ISN'T it? / If you're COMfortable / while you're DOing it, / you're PRObably / doing it WRONG."

---

## 내 문장으로 응용하기

- **원문 패턴:** If you're [편한 상태] while you're doing it, you're probably doing it wrong.
- **응용 1:** Learning a language is a lot like going to the gym, isn't it? If it feels easy, you're probably not pushing hard enough.
- **응용 2:** If you're not a little nervous before a presentation, you probably don't care enough about it.
